# 参考站拆解：Bumble 与粗门（内部）

2026-10-07。依据：Sylvan 提供的截图（我们这边的网络访问不了这两个站，没看到视频、动效、滚动交互）。带「推测」的是判断，不是站点明说的。

## Bumble
- **颜色**：整屏饱和黄 + 炭灰字（不是纯黑），再配一档浅黄。一个颜色扛起全部品牌。
- **首屏**：撑满宽度的巨大字标，零文案。品牌本身就是画面。导航是悬浮的白色胶囊。
- **一句话**：「We exist to bring people closer to love.」大字 + 副文一行 + 一个黑色胶囊按钮。说它是什么，不解释功能。
- **身份信号**：真人照片扇形叠放，竖排黄色胶囊标签（Outdoors / Running / Dog parent）。
- **产品**：两张卡各一档黄，手机界面只露一半，配真人照 + 一句话 + 下划线链接（Find your person）。
- **证明**：整屏真实夫妻引语，署名具体（Leslie & Thomas, married in 2025）。
- 圆角统一且大。

## 粗门 Cumen
- **首屏**：全屏真实视频（两人骑车），压暗；标题「粗门，一起玩！GO!」是涂鸦贴纸字（荧光绿填充、黑描边、微倾斜、手绘小线）；副标题三个词「小众运动 ｜ 潮酷体验 ｜ 结识好友」。
- **文案**：「粗门是一种年轻人结伴的新方式。」+「这里，……」排比四行。像宣言，不像功能列表。
- **颜色**：荧光绿 + 黑 + 薄荷底，背景等高线纹理。
- **贴纸**：羽毛球、自行车、猫头的手绘线稿盖在手机界面边缘，页面是活的。
- **产品**：手机界面是真实密度（城市、「2500万人在玩」、带图活动卡、话题标签）。
- **按钮**：微信小程序、小红书小程序、App Store、Android 四个黑色圆角方块，渠道本地化。
- 推测：「粗门」是「出门」的谐音，品牌围绕「走出门」。

## 共同点
招牌颜色撑起全页；首屏几乎没字；身份用标签表达；产品展示得像真的且不完整露出；有一个个性载体（巨型字标 / 贴纸）；文案是宣言和动作。

## 我们上一版的问题（对照）
文字下的荧光笔条像笔记本；首屏文字多、猫小、无视觉重心；每节都是黑边框白卡片像线框图；产品界面规整空洞；没有人、没有个性载体（奶牛猫只是点缀）；系统字体；文案在解释功能而不是宣告「我们是谁、为谁」。

## 约束
- Bumble 占用了黄色，我们不能再把黄色当招牌色。
- 粗门卖「一起」，我们的差异是「一个人也能练对」，niche 要从这里找。
- 手机界面要更有密度，但演示数据仍须明示为演示。
- 真人照片我们没有素材；奶牛猫是个性载体。

## 方向（等 Sylvan 调研结论后定）
A 偏 Bumble（招牌色整屏 + 奶牛猫超大 + 身份标签 + 手机界面露一半）；B 偏粗门（贴纸字 + 贴纸猫盖在手机边缘 + 「这里，」排比 + 三词副标题）；C 混合：Bumble 的克制结构 + 粗门的贴纸能量，奶牛猫做个性载体。先出首屏小样，选定后再做整站。

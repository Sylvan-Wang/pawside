# 付费意向实验设计

> 2026-11-16 例程产出（周计划 #53 周一任务）。**只是设计，不开工、不上线、不定价。** 上线前要 xxa 在周五决策场批（涉及对外说法和定价，属于硬规则里「等 xxa」的事）。

## 1. 要回答的问题

一个问题：**有没有人愿意为 Pawside 的哪一部分付钱，愿意付多少、按什么方式付。**

不回答：最终定价、收费系统、真的收钱。实验期间不收任何钱，也不让任何人以为自己付了钱。

## 2. 输入：信号说了什么（#26，11-07 到 11-16 共 4 次信号包）

| 说法 | 例子（App Store 评论，匿名） | 对实验的含义 |
|---|---|---|
| 基础记录被锁进付费墙，反感很强 | MyFitnessPal 扫码从免费变付费；「改快速添加的热量要删了重填，这价不值」；「付了钱还天天弹窗催订阅」 | **记录本身、改自己的目标、改自己的记录，永远免费** |
| 便宜或买断被主动夸 | Strong「NO SUBSCRIPTION」「付了 $29 一年」；Hevy「$2.99/月值」；r/apps 11-16「讨厌订阅的人，一次性愿意付多少？」 | 价格选项里要有**买断**和**低月费**，不只问月订阅 |
| 愿意为「替我想」付钱 | Fitbod ★5「$80 一年值，打开就知道练什么」「省得每次进健身房自己排」 | 可收费的候选是「替你排、替你看」的部分，不是记录 |
| 付费后体验变差会流失 | MacroFactor「年费买了，结果天天在改错数据」；MyFitnessPal 付费用户账号丢失要退款 | 实验文案不承诺还没做的东西 |

局限：这些都是英文 App Store / Reddit 的方向性信号，不是 Pawside 用户说的话。

## 3. 收费边界（实验里先这样问，结果出来再定）

| 永远免费 | 候选付费（实验里问） |
|---|---|
| 逐组记录、饮食记录、体重、有氧 | 小爪一句话记录的高用量（模型调用有成本） |
| 改自己的目标、改 / 删自己的记录 | 训练和饮食的文字反馈（每日、每周） |
| 训练方法和今天练什么 | 以后的「按动作看重量走势」等进阶视图（#48，还没做，**只在内部讨论，不进实验文案**） |
| 导出自己的数据 | |

规则：实验文案只写**今天已经能用**的东西（`lib/site/features.ts` 里 `live` 的），按 `MESSAGE_HOUSE.md` 第 9 节不写结果承诺、用户数。

## 4. 实验形式

**推荐 A：App 内一张「你会怎么付」卡片（开关后，默认关）。**

- 位置：用户**第 3 次完成训练**后，训练总结页底部，只出现一次（不打断记录，不弹窗；#43 打扰式激励的反面例子是 MyFitnessPal 每记一次就弹「做得好」）。
- 内容：一句话说明「Pawside 现在免费。我们在想以后怎么收费才合理，记录永远免费」，然后一题：
  - 如果「小爪记录 + 每日反馈」以后要收费，你会选：① 一次性买断 ② 每月几块钱 ③ 只用免费部分 ④ 不会再用
  - 选 ①② 的，再给 3 个价位（人民币和美元各一套，按语言显示），可以跳过。
- 记数：新表只存 `选项、价位、语言、注册天数段、提交日期`，**不存自由文本，不和饮食、训练内容关联**。需要新表 → 是线上数据库结构改动，**要 xxa 批**。
- 撤销：关掉开关即消失；表可以整表删除（删除也等 xxa）。

**备选 B：官网「种子用户」表单加一个可选问题**（「以后你更愿意怎么付？」）。复用 `seed_signups`，加一列 `pay_preference`。比 A 快，但问的是还没用过的人，信号弱；而且是官网新增对外内容，要 xxa 批。

**备选 C：不做产品改动，xxa 和真实用户各聊 15 分钟**，用上面同一道题口头问。零开发，但只有个位数样本。

**为什么推荐 A：** 只问用过的人（第 3 次训练后），问的是「怎么付」而不是「付不付」，不收钱、不假装能付款。C 可以和 A 同时做。

## 5. 成功线和判定（跑满两周）

现实：现在真实用户 2 个，本周增长目标是新增 3 个。**两周内能看到这张卡的人可能不到 5 个，统计上什么都证明不了。** 所以判定写成「够不够做下一步」，不写成「验证了付费」。

| 结果（两周内） | 判定 | 下一步 |
|---|---|---|
| 看到卡片的 ≥ 5 人，且 ≥ 2 人选 ① 或 ② | 有付费意向的苗头 | 周计划里加「定价方案」待批：选买断还是月费、价位 |
| 看到卡片的 ≥ 5 人，选 ① ② 的 < 2 人 | 现在的功能不够付费 | 不做收费，先做留存（#48 进步走势、#40 记完能改） |
| 看到卡片的 < 5 人 | **样本不够，不判定** | 实验继续，同时把力气放在拉新上；周复盘只报人数，不报比例 |

记数方式：例程每周五只读汇总（按选项计数），写进周计划复盘「指标」那一行。不看个人记录。

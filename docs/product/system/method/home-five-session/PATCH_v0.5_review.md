# Pawside｜居家轻力量·现有前端适配审阅稿 v0.5

审阅日期：2026-10-21。状态：待内容验收的上架审阅稿，尚未发布。

## 1. 方法论定位

适用画像：18岁以上、工作繁忙、居家空间有限，希望减少选课成本、持续运动的普通成人。完整支持无弹力带、无哑铃、无跑步机的纯徒手训练；瑜伽垫为舒适性用品，不是器械门槛。用户可自由点选、排序、删除和组合模块；四次力量相关训练与一次有氧的五日循环仅作为可编辑的推荐模板，五日不是连续五天或每周必须完成五次。

价值承诺：今天打开就知道练什么；忙时有短版，漏练后可以接着来。

目标：建立可持续的训练习惯，支持全身力量和体能发展。具体体形变化取决于长期训练、负荷、饮食和恢复，不承诺局部减脂或固定期限的外形变化。

素材主线：周六野Zoey的热身与阻力带臀部内容、Pamela Reif的新手臀腿与上肢/核心内容。组合顺序、补充动作、剂量、缩短和恢复规则由Pawside编排；不是两位创作者的官方联合课表或经验证的独立训练体系。

## 3. 五次训练的总体编排

本版 patch：动作库与GIF承担日计划展示和执行；来源视频仅用于教程参考。撤回“完整视频＋补充动作”的默认方案，避免未经拆解的视频与动作处方重复堆量。

| 顺序 | 名称 | 动作版默认骨架 | 来源用途 |
|---|---|---|---|
| A | 臀腿基础 | 热身 → 深蹲 → 臀桥 → 提踵 → 收尾 | Z01/P01作为候选参考，待逐动作核验 |
| B | 上肢基础 | 热身 → 划船 → 俯卧撑 → 可选侧平举 → 收尾 | P02作为候选参考，器械与动作映射待核验 |
| C | 舒适有氧 | 轻松进入 → 跑步机快走或无跳跃踏步 → 减速收尾 | 采用Pawside明确处方 |
| D | 臀腿补充 | 热身 → 髋铰链/硬拉 → 分腿蹲 → 侧卧抬腿 → 收尾 | Z02作为候选参考，待逐动作核验 |

器械版采用第5节剂量，纯徒手版采用第3B节。以上为Pawside编排，不声称还原创作者原课表；每个动作绑定已有标准素材，不将尚未核实的视频片段用作精确教学关联。

时长按动作、组次、左右侧、休息和转换动态累计；不再按视频标题分钟数推算。四次力量相关训练不等于四次高强度训练，不承诺最大化增肌效果。

默认8天示例：第1天A、第2天B、第3天休息、第4天C、第5天D、第6天休息、第7天E、第8天休息。之后继续循环，可调整。同一肌群较费力训练原则上间隔约48小时，并结合疲劳和不适调整；额外有氧计入实际负担。

## 3A. 自由组合：适配现有训练流程

撤回此前“首页新增今日推荐/自由组合/我的组合三个入口”的设计。自由组合是已有训练内容选择/编辑环节的能力，不预设新首页、新导航或新页面。先在现有onboarding补充场地和器械字段，再在现有方法论/计划/动作选择及执行流程内接入适配内容；具体页面、组件、字段与路由必须核对当前前端和代码后确定。

能力流转（不代表新页面）：继承个人场地与器械 → 在已有内容选择处按条件筛选 → 用现有增删/替换/排序交互组合训练 → 更新预计时长 → 沿用已有开始、执行、记录、恢复与完成流程。若当前前端不支持某项操作，先定位扩展原组件，不另建整套课程编辑器。收藏/个人副本仅在已有对应能力时复用，不因本方法论自行新增入口。

模块粒度：复用现有动作库、计划及编辑能力。可选组合按结构化动作/动作组组织，每个动作关联GIF或姿势帧、处方和提示；原视频不是默认可添加的训练模块。不自动把视频拆成未经核实的动作。用户明确重复添加动作时保留独立实例并提示重复，不静默删除。

五日模板进入后可加减或替换模块。编辑只影响本次训练或用户已有计划副本，不覆盖原始方法论。是否保存为长期计划沿用现有交互，不强加“保存为我的组合”这一新产品概念。

系统默认建议热身在前、放松在后，可一键整理；用户仍可调整。明显重复、预计超时、器械不匹配、连续高负担模块分别给出具体提示，允许删除/替换/降低剂量。器械不匹配的模块不会自动标记为纯徒手可执行；用户切换到有器械模式或选替代后再加入。

记录实际完成内容，推荐只是草稿。自由训练不自动推进五日循环；如果从模板进入并修改，则结束时可选择“计为本次模板训练”或“另存自由训练”。漏做某模块不产生必须补齐的欠账。

组合总时长 = 动作执行＋换边＋组间休息＋动作间转换＋热身收尾，避免重复计算。查看教程的时间与实际训练时间分开；已核实动作标签用于重复刺激提示。

## 3B. 完整纯徒手五日模板

纯徒手 = 不要求弹力带、哑铃、跑步机、椅子或其他训练器械。地面应平稳，垫子可选。墙面/扶物是用户主动选择的辅助分支。

| 模板日 | 纯徒手默认组合 | 忙碌短版 |
|---|---|---|
| A 臀腿基础 | BW-WARM → BW-LOWER-A → BW-COOL | 主模块每动作1组，保留热身/收尾 |
| B 上肢基础 | BW-WARM → BW-UPPER → BW-COOL | 俯卧撑1组、W抬臂1组，保留热身/收尾 |
| C 舒适有氧 | BW-CARDIO；可自选增加一个完整有氧模块 | 单个15分钟模块即为短版 |
| D 臀腿补充 | BW-WARM → BW-LOWER-B → BW-COOL | 分腿蹲1组/侧、臀桥1组，保留热身/收尾 |
| E 上肢与核心 | BW-WARM → BW-UPPER简版（俯卧撑/W抬臂各1组）→ BW-CORE → BW-COOL | 上肢简版＋死虫式1组/侧，保留热身/收尾 |

上述组合按实际模块/休息累计，不强行声称都是30分钟，也不将短版一概标为15分钟。用户在纯徒手与器械版之间切换时，先预览将替换的模块；已完成的动作/组次保留，只替换尚未开始的部分。

纯徒手素材拓展仍优先寻找两位创作者的适配官方内容；未核实的无器械视频不伪造为已审阅来源。在验收完成前，动作版可以作为独立审阅内容，教程关联维持候选状态。

## 3C. Onboarding：场地与器械档案

在已有目标等设置之后，增加“通常在哪里训练”和“有哪些可用器械”。可稍后设置；未填时先展示纯徒手入门内容并说明可修改，不把未填写持久化为“确认无器械”。

第一步，常用场地（多选）：家里 / 健身房 / 户外。默认今日使用哪个场地可单独选择；有健身房不代表用户每次都在健身房。

第二步，可用器械（按场地记录、多选）：小哑铃 / 短环形弹力带 / 长弹力带 / 跑步机 / 其他。另设“无器械，仅徒手”互斥选项；选择任一器械后取消“无器械”，但徒手内容仍可推荐。不要求一开始填完重量；哑铃重量/可调范围、弹力带类型/阻力可后续补充。短环带和长带仍区分。

健身房分支可先选“有自由重量区”“有固定器械”“有有氧器械”，允许不知道/稍后补充。笼统的“有健身房”不能自动满足具体器械要求；当前素材库只推荐已经收录且器械已匹配的内容，未开发的健身房训练不自动生成或宣称已支持。

第三步，可选限制：空间小 / 不方便跳跃或有噪音限制 / 不方便铺垫或做地面动作。均可稍后修改，不因选择居家自动推断这些限制。

使用规则：

1. 长期档案作为默认推荐条件：目标＋当前场地＋实际器械＋空间/跳跃偏好。
2. 每次进入训练先显示“今天：家里 · 小哑铃”，一键调整本次场地/器械；临时改变不覆盖长期档案，另有“同时更新常用设置”选项。
3. 纯徒手内容对有器械用户同样可见；有器械是增加可选内容，不是强迫使用器械。
4. 推荐默认满足全部必需器械；不匹配内容可在用户主动选择“查看全部”后显示，但明确缺少什么，并提供已经定义的替代，不自动将有器械视频转换成徒手视频。
5. 短环带、长带、哑铃不能互相默认等价；墙面和稳固支撑也按模块要求独立标记。
6. 自由组合继续支持场地、器械、部位、时间、强度和跳跃限制筛选。切换场地后提示组合中不匹配的模块并允许替换，保留已完成记录。

用户档案建议字段：training_locations / default_location / equipment_by_location / optional_equipment_details / space_constraints / impact_preferences。session保存本次实际场地、器械和所用模块快照；字段为概念建议，接入时需对齐真实代码契约。

## 4. 统一动作流转规则

### 4.1 训练前

沿用现有训练入口 → 继承onboarding场地/器械 → 在现有方法论或训练配置环节选择/调整内容 → 预览预计时长 → 沿用现有执行流程。入口名称与控件形式以当前前端为准。

器械分开标记：瑜伽垫、短环带、长弹力带、哑铃、稳固墙面/椅子、跑步机。只有长带不能自动视作有短环带。

第一循环以熟悉动作和适应训练量为主。无训练经验或恢复不足时允许减少单次内容、拉长循环；五次不是必须完成的周配额。

### 4.2 动作卡、GIF与完整教程弱入口（本次patch）

主流程：方法论/日计划 → 动作卡直接显示现有GIF/姿势帧、动作要点、处方与休息 → 执行并记录 → 下一动作。用户无需打开外部视频也能完成训练；缺素材时采用已有合格姿势帧或提示，不强制跳出。

仅在每个动作配置/详情的内容最底部放一行次级文字链接，位置在动作说明和处方之后，视觉低于开始/完成/下一组等主操作：

> 动作还不清楚？查看完整视频教程 ↗

不增设日计划级“相关完整教程”区域、视频大卡片、自动播放或训练中弹窗。没有核实相关教程时隐藏链接，不放无关视频占位。若一个动作有多个来源，默认只显示已核实、最相关的一项；完整出处保留在内容元数据中。只有精确片段经核验才允许带时间戳，否则打开完整视频。

GIF可以来自已有标准动作库，教程来自另一官方来源，分别保存出处；不可将标准GIF标注为从该视频提取，也不可把名称相似当作动作等价。

打开前先持久化本次计划快照、session、动作实例/顺序、当前组与侧、已保存实际记录、未提交输入和计时状态。沿用现有新标签/外链方式打开；应用的动作/休息计时暂停，不将外部停留时间计为训练或完成量。保存失败时保留当前状态并提供重试，不带着未保存进度直接跳出。

返回后恢复原动作和进度，计时保持暂停，由用户主动继续。若页面重载，仍可恢复；多次返回不重复创建session、记录或推进循环。可在原记录区域显示一次非阻断文字“已回到刚才的动作，继续或补记实际完成量”，不强制弹窗或要求重复填写。

用户只看教程则继续原处方；已跟练则复用原有动作记录补记实际组次/时间，允许部分完成与跳过。更新已有组记录而非重复新增；未练动作不自动完成。视频与计划不同时只记实际做过的部分，禁止一键推定整天完成。

外链失败时保留GIF与主流程，并可重试；无法观察外部播放进度时不声称已观看、看完或播到某秒。

### 4.3 结构化动作执行

动作说明与无负重试做 → 第1组 → 确认完成并记录实际次数/阻力 → 休息 → 第2组 → 下一动作。

以下均为Pawside审阅提案：常规动作2组；组间休息60–90秒，需要时延长；动作间换位30–60秒。选能在动作稳定的前提下完成目标范围、结束时感觉还能再做约2–3次的负荷。没有动作基础时先徒手/轻负荷，不根据创作者用的重量照搬。

左右侧动作的一组：左侧 → 换边15–30秒 → 右侧 → 记录两侧各自完成量 → 组间休息。下一组可先做右侧；两侧完成才算完整一组，允许部分记录。

不要为了凑够视频时间或次数牺牲动作。疼痛、眩晕或明显异常不适时停止该区块；疼痛不被系统标记为普通的“训练很努力”。

### 4.4 收尾

轻松走动与舒适范围拉伸2–4分钟 → 本次轻松/合适/吃力 → 有无不适 → 保存实际完成内容 → 显示一个具体反馈 → 预览下次训练。

放松不承诺治疗体态、消除酸痛或改善疾病。

## 5. 器械版动作处方及替代

本节均为Pawside原创处方；动作GIF沿用现有动作库。无适配器械时切换第3B节完整纯徒手版，不只删掉器械动作而留下残缺训练。每次保留3–5分钟热身、2–4分钟收尾；组间60–90秒，换位30–60秒，可延长；左右侧按第4.3节分别记录。

| 日 | 常规主动作（按顺序） | 短版 |
|---|---|---|
| A | 杯式深蹲2×8–12；臀桥2×10–15；提踵2×10–15 | 每动作1组 |
| B | 支撑单臂哑铃划船2×每侧8–12；墙面俯卧撑2×8–12；可选轻哑铃侧平举1×8–12 | 划船1组/侧、俯卧撑1组，侧平举可省略 |
| C | 跑步机慢走5分钟 → 舒适快走20分钟 → 慢走5分钟 | 3＋9＋3分钟 |
| D | 哑铃罗马尼亚硬拉2×8–12；扶物分腿蹲1–2×每侧6–10；侧卧抬腿1–2×每侧8–12 | 每动作1组，保留换边 |
| E | 划船1×每侧8–12；墙面俯卧撑1×8–12；死虫式2×每侧6–8；鸟狗式2×每侧6–8 | 上肢各1组＋死虫式1组/侧 |

提示与替代：深蹲脚掌稳定、幅度可控，可选稳固椅子坐站；划船支撑稳定、不扭转躯干，已有合格教学时可选长带划船；俯卧撑保持身体整体可控，稳固台面版仅在支撑适配时采用；硬拉膝微屈、髋向后，不追求触地，不熟悉时先做无负重髋铰链或臀桥；分腿蹲不稳可换深蹲；核心动作缓慢控制，不憋气。实际替代关系需要记录。疼痛时停止，不强制完成替代。

有氧以个人能力调整速度/坡度，舒适快走可说完整句子；无跑步机采用第3B节无跳跃有氧。额外有氧单独记录，用户明确选择替代C日时才推进循环，不因饮食自动追加。

短版保留热身与休息，不用倍速或压缩动作赶时间。原视频候选仅用于内容核验、教学参考，不在以上动作之前或之后默认整段叠加。

## 6. 短版、疲惫与中断

短版是另一份明确处方，不把所有视频倍速、随机截断或将全部休息等比压缩。短版完成记为“短版完成”，保存真实训练量，不伪装为常规版全部完成，也不展示失败文案。

疲惫：提供短版/休息；已经完成部分动作时可减少剩余辅助动作。正常但吃力：延长休息或降低阻力。疼痛/明显异常：停止相关内容；有持续症状时不自动给加练建议。

中断保存：循环序号、session_id、区块ID、已完成组、左右侧、实际时长、器械阻力、替代/跳过原因。恢复时先确认当前状态，再选择继续/短版收尾/结束本次。

不追踪外部播放器进度，不猜测观看位置。回来恢复Pawside动作状态；已练部分保留，不强制从头重练，记录规则见第4.2节。

整天未练：循环指针不变，日历顺延。部分完成：用户可结束并推进，或保存等待继续；系统给出明确选择，不无限积累待补任务。长时间中断后以轻量版恢复，不自动增加训练量。

## 7. 递进与复盘

前两次接触每个训练日：熟悉动作，动作允许仅1组；不要求短期内练满五次。

之后根据单动作表现递进：连续两次动作稳定、无不适、达到次数上限且仍偏轻松时，只调整一个变量——适当增加阻力，或先增加范围内次数；必要时再加1组并重新估算时长。更换阻力后回到次数范围下端。不按日期或体重变化自动加重量。

递进围绕动作稳定性、实际阻力与完成量，不用视频观看完成率或不断换更累的视频代替。器械无法提供足够刺激时，明确当前版本限制，再选择已验收的进阶动作。

每次结束仅问：难度轻松/合适/吃力；有无不适。每循环结束看完成次数、实际时间、回归情况与选用阻力，不用出汗或酸痛评估效果。

反馈例句：“今天完成了上肢短版，两侧划船都有记录。下一次继续有氧日。”避免夸大热量消耗、不许诺局部变瘦、不把漏练写为意志力差。

## 8. 有氧与时间预算

循环总时长按所选动作和休息重新估算。用户每周有3–4小时是可用预算，不是必须填满的任务。额外快走逐步增加，并与睡眠、疲劳和恢复一起判断。

一节30分钟有氧不等于已经达到整周有氧活动建议。CDC一般成人建议为每周至少150分钟中等强度有氧或相当的高强度活动，并在至少两天覆盖主要肌群；有氧可分段累计。本模板的力量时长不全部直接计为中等强度有氧。

## 12. Retention与验收 patch（v0.5）

目标：在Pawside内看懂并完成训练，离开后接得上，下次愿意继续。视频点击率不作为成功目标，不以阻止用户查看教程换取停留时长。

| 指标 | 口径 | 用途 |
|---|---|---|
| 教程返回率 | 打开教程的唯一session中，在同session恢复Pawside动作页的比例；同时报告当日返回 | 观察外跳损失；无法观测是否播放 |
| 返回后继续训练率 | 已返回session中，之后至少保存一条实际训练记录的比例 | 判断是否接回主流程 |
| 返回后结束训练情况 | 已返回session的完成/短版完成/部分结束/放弃分别统计 | 不把部分训练自动判为失败 |
| 下一次训练回访 | 此次训练后7日内再次开始训练的用户比例 | 与只打开页面区分；非因果比较 |
| 持续使用 | 每周实际训练次数、连续4周每周至少一次训练的比例；D7辅助观察 | 衡量长期习惯，避免打卡惩罚 |

复用现有埋点系统；概念事件为tutorial_open、workout_resume、exercise_record_saved、session_end和下一次session_start。最小关联为匿名用户标识、session_id、动作实例、method_version、时间与结束类型。exercise_record_saved按记录ID去重，resume按外跳次数区分并按session聚合。外链点击不冒充播放成功；跨标签、浏览器终止导致的不可观测情况单列未知。按纯徒手/器械、短版/常规和新老用户拆分；样本不足时先看实际掉队路径，不设虚构达标阈值。

实施验收：

1. 动作配置底部只有次级文字教程入口；日计划和主操作没有新增视频卡片或教程弹窗。无有效链接时隐藏，GIF执行不受影响。
2. 点开、未看、关闭、返回、页面刷新、浏览器重启后，计划顺序、动作、组次/侧、输入及已记录数据正确恢复；计时等待主动继续，不累计外部时长。
3. 重复返回/重复保存不增加session或重复记录；不自动完成动作/当天计划，不自动推进五日循环。
4. 已跟练但计划不完全相同时，只补记实际动作；允许跳过与部分结束，保留已有记录。
5. 外链不可达、保存失败、素材缺失各有可恢复处理；不让用户被迫跳出或丢失输入。
6. 纯徒手筛选、自由组合、短版与器械替换继续沿用现有流程，调整未开始内容不覆盖完成记录。
7. 教程点击、返回、实际记录和下一次训练可关联去重；对比前后留存时注明用户条件、观察窗口及样本量，不把相关性当因果。

## 1. 定位

适用：18 岁以上、工作忙、居家空间有限的普通成人。徒手版不需要任何器械；小器械版需要哑铃（弹力带可选，见动作说明）。

价值承诺：打开就知道今天练什么；忙时有短版；漏练不欠账。

目标：建立可持续的训练习惯。不承诺局部减脂或固定期限的外形变化。

五日是推荐循环，**不是每周五次的配额**：A 臀腿基础 → B 上肢基础 → C 舒适有氧 → D 臀腿补充 → E 上肢与核心。同一肌群较费力训练约间隔 48 小时。

组次、休息均为 Pawside 编排，不是任何创作者的官方课表；休息统一 60–90 秒（该方法自己声明，与现有方法的 45–90 秒无关）。

## 2. 五日处方

每次含 3–5 分钟热身、2–4 分钟收尾。时长按动作、组次与休息累计，不按视频标题推算，不统一标称 30 分钟。动作选能稳定完成、结束时还能再做约 2–3 次的负荷；没有基础先徒手或轻负荷。疼痛、眩晕等异常不适时停止。

### 徒手版（器械要求：无）

| 日 | 内容（常规） |
|---|---|
| A 臀腿基础 | 深蹲 2×8–12；臀桥 2×10–15；提踵 2×10–15 |
| B 上肢基础 | 跪姿俯卧撑 2×6–10；俯卧 W 抬臂 2×8–12；俯卧反向雪天使 1×6–10 |
| C 舒适有氧 | 轻松踏步 3 分钟 → 舒适节奏踏步/侧向并步 9 分钟 → 轻松踏步 3 分钟（共 15 分钟） |
| D 臀腿补充 | 分腿蹲 1–2×每侧 6–10；臀桥 2×10–15；侧卧抬腿 1–2×每侧 8–12 |
| E 上肢与核心 | 跪姿俯卧撑 1×6–10；俯卧 W 抬臂 1×8–12；死虫式 2×每侧 6–8；鸟狗式 2×每侧 6–8 |

### 小器械版（器械要求：哑铃）

| 日 | 内容（常规） |
|---|---|
| A | 杯式深蹲 2×8–12；臀桥 2×10–15；提踵 2×10–15 |
| B | 支撑单臂哑铃划船 2×每侧 8–12；墙面俯卧撑 2×8–12；可选轻哑铃侧平举 1×8–12 |
| C | 同徒手版 C（无跑步机，不要求跑步机） |
| D | 哑铃罗马尼亚硬拉 2×8–12；哑铃分腿蹲 1–2×每侧 6–10（可扶墙/稳固物保持平衡）；侧卧抬腿 1–2×每侧 8–12 |
| E | 单臂哑铃划船 1×每侧 8–12；墙面俯卧撑 1×8–12；死虫式 2×每侧 6–8；鸟狗式 2×每侧 6–8 |

说明：
- v0.5 的跑步机 C 日（慢走 5 → 快走 20 → 慢走 5）不再作为默认；如需要，作为后续独立内容，不在本版。
- 「每侧」只是处方文字；记录时填一组的总次数或每侧次数，自行约定，系统不拆侧。
- 徒手版没有背部拉力动作，这是已知限制，不标注为等价于划船。
- 动作提示：跪姿俯卧撑躯干可控、肘不过度外展；W 抬臂与反向雪天使小幅、舒适范围；分腿蹲不稳则换深蹲；核心动作缓慢控制、不憋气；不适就停，不强制替代。

### 短版

开始训练时打开「短版」：每个动作只做 1 组，保留热身与收尾，有氧日 15 分钟本身就是短版。做完记为**完成**并推进循环，保存真实训练量。不用倍速或压缩休息赶时间。

### 跳过与中断

- 可跳过单个动作。跳过多少仍算完成，**沿用现有完成判断**，本方法不另设阈值（实现时核对）。
- 中途「提前结束」：保留已记录的组，不算完成当天，指针不动，下次还是这一天（现有行为）。
- 整天没练：指针不动，日历顺延，不欠账。长时间中断后建议从短版回归，不自动加量。

## 3. 器械与方法选择

沿用 onboarding 现有三选一：`full_gym` / `basic_equipment`（哑铃、弹力带）/ `home_bodyweight`。不新增场地、器械字段。

每个方法声明需要的器械等级：**徒手 < 小器械 < 健身房**。

| 用户器械 | 可直接使用 | 灰显（点击确认后可进入） |
|---|---|---|
| 完整健身房 | 全部方法 | 无 |
| 基础器械 | 居家徒手版、居家小器械版 | 三分化、四分化 |
| 居家徒手 | 居家徒手版 | 居家小器械版、三分化、四分化 |

- **全部方法都展示**，不要只显示能用的（会显得方法少、场景被主动缩减）。灰显的颜色放淡，排在可用项下面。
- 点击灰显项弹确认：「该方法需要 xxx 才能执行，确定切换吗？」确认后允许进入。
- 在方法列表中，「居家徒手」与「居家小器械」可展示为两项；底层是**同一个方法的两个版本**，选哪项即选哪个版本。已进入后可在该方法内切换版本，切换只替换尚未开始的内容，已记录的组保留。
- 用户档案不确定时（旧用户或未选），按「居家徒手」展示可用项，不把未填写当作「确认无器械」。

## 4. 动作展示与教程链接

主流程：日计划 → 动作卡显示 GIF/姿势帧、要点、处方、休息 → 逐组记录 → 下一个动作。不必打开外部视频就能练完。缺素材时按现有规则降级为文字提示。

每个动作详情**最底部**，动作说明与处方之后，放一行次级文字链接（有已核验链接才显示）：

> 动作还不清楚？查看完整视频教程 ↗

- 一个动作最多一个链接，B 站。查找由其他 agent 完成；**必须确认发布账号是对应创作者**，只凭同名不算官方，页面打不开不算通过。
- 没有核验过的链接就隐藏，不放无关视频占位，不加日计划级的教程区、视频卡片、自动播放或弹窗。
- 打开前沿用现有草稿保存机制保存进度；沿用现有新标签方式打开；外部停留时间不计入训练时长。返回后回到原动作，计时保持暂停，由用户主动继续（现有覆盖程度待核，见 CONFLICT_CHECK）。
- 不追踪外部播放进度，不声称「看完」。
- GIF 与教程出处分别保存，不将标准 GIF 标注为取自该视频。

## 6. 递进与反馈（沿用 v0.5 §7，简化）

- 每个训练日前两次接触可只做 1 组。
- 连续两次动作稳定、无不适、达到次数上限且仍偏轻松，才调整**一个**变量：加阻力（小器械版）或先加次数；必要时再加 1 组。不按日期或体重自动加量。
- 结束只问：轻松 / 合适 / 吃力；有无不适。不用出汗或酸痛评估效果。
- 反馈不夸大热量消耗、不许诺局部变瘦、不把漏练写成意志力差。
- 有氧：一节 30 分钟有氧不等于达到整周建议（CDC：每周至少 150 分钟中等强度有氧，并至少两天覆盖主要肌群），本模板力量时长不全部计为有氧。

## 8. 验收

1. 徒手用户全程不会被要求器械；小器械用户能看到并选择徒手版。
2. 方法列表全部展示，灰显项点击有确认，确认后可进入。
3. 短版开关、跳过、提前结束、整天未练的推进规则与第 2 节一致。
4. 教程链接底部单行、无则隐藏；点开后回到原动作，计时不累计外部时长。
5. 居家用户不再被首页「暂不可用」整卡拦住；三分化/四分化的现有行为不变。
6. 完成 Z01/Z02/P01–P03 的核验，之前不上线教程链接和官网说法。

## B8 · 开屏恢复卡

**现状：**首页上有一张"今天状态怎么样？"的卡片，但不会主动弹出，所以线上 `recovery_checkins` 表一直是空的。

**改成：**
- 每天第一次打开 App（任何页面都算）时，从底部弹出一次。点了"完成"或"跳过"之后，当天不再弹。
- 训练进行中不弹。

**问题 1：睡眠**
- 标题："早上好，昨晚睡得怎么样？"
- 5 个文字选项：很差 / 不太好 / 一般 / 还行 / 很好，依次存为 `sleep_quality_self_report` 的 1–5。
- 选项上**只显示文字，不显示数字**。

**问题 2：酸痛（按三分化匹配部位）**
- 只有上一次完成的训练在"昨天或前天"时才问；否则整题不出现。
- 标题按上一次训练的 `split_key` 生成："昨天练了推，胸、肩、三头还酸吗？"
  - 前天练的就把"昨天"换成"前天"。

| split_key | 显示名 | 部位 |
|---|---|---|
| push | 推 | 胸、肩、三头 |
| pull | 拉 | 背、二头 |
| legs | 腿 | 大腿、臀 |

- 3 个选项：不酸 / 有点酸 / 很酸，存到 `post_workout_recovery_self_report`，分别存 5 / 3 / 1。数值越大恢复越好，和现有 `describeSelfReport` 的方向一致。不需要改表结构。

**回答之后显示一句话**
这句话由规则生成，不调用模型，用 `method_enrollments.next_split_key` 判断今天练什么：

| 情况 | 文案 |
|---|---|
| 今天练的部位和酸的部位不重叠 | "今天是{拉}日，主要练{背和二头}，和{昨天}的部位不重叠。" |
| 今天练的部位和酸的部位重叠（例如重复练同一天），并且选了"很酸" | "今天还是练{胸、肩、三头}，热身时多做一组轻的，先感受一下状态。" |
| 今天还没有训练安排 | 不显示 |

**不能说的：**不能根据自评改处方，也不能说"今天别练"（Product §8，METHOD_RULES）。恢复只作为背景信息，以后在阶段 C 的恢复引擎里才会用到。

**验收：**
- 分别用昨天推、拉、腿三种情况各截一张图，外加"前天练过"和"3 天没练"两种情况。
- 跳过以后当天不再弹。
- 表里存进去的值正确。

## B9 · 每日日志页：训练卡

文件：`app/history/[date]/page.tsx`；首页"今日训练"入口可以复用同一个组件。

**卡片结构（从上到下）：**
1. **标题行**：`{推}日 · 第 {n} 轮`，右侧显示"完成动作数 / 计划动作数"。
2. **教练的一句话**：取当天训练反馈的 headline。没有 AI 结果时不显示这一行，不要用占位文字。
3. **每个动作一段**：
   - 动作名；是关键组的动作加一个"关键组"标签。
   - 右侧和上次同一个动作比较，只显示一种结果，规则如下（上次 = 同一 split 上一次完成的训练，同一动作最重那组的重量和次数）：
     - 同样重量下次数多了："↑ 比上次多 N 次"
     - 重量加了："↑ 重量 +N kg"
     - 找不到上次："第一次练"
     - 其他情况：什么都不显示
   - 下面一排小块，每块代表一组，写"重量×次数"。热身组写"热身 20×15"；休息-暂停组写"10+10"这样的分段；计划里有但没记录的组用虚线框，写"第 4 组 · 8 次 · 未记录"。**不写"没完成"。**
4. **动作的显示顺序**：主项和有关键组的动作显示在前，其余动作折叠成一行"上斜哑铃卧推 · 双杠臂屈伸 · …  展开"。
5. **不显示训练时长**（M008）。

**数据来源：**`workout_sessions` + `exercise_executions` + `set_executions` + `set_prescriptions`，不再只读 `workout_logs` 的类型和时长。和上次的比较可以复用 `lib/coach/workout-context.ts` 里的 `loadLastTime`（需要导出）。

**验收：**
- 用 09-24 那次推的真实数据截图：能看到"热身 20×15 · 29×12 · 27.2×10 · 第 4 组未记录"。
- 页面上看不到"19924"或任何时长。

## B10 · 每日日志页：饮食卡

**卡片结构：**
1. **标题行**：左边"饮食"，右边"还可摄入 X kcal"。超出目标时写"超出 X kcal"，不加任何评价。
2. **两条进度条**：热量和蛋白质，分别显示"已摄入 / 目标"。没设目标时只显示已摄入，不画进度条。
3. **每餐一行**：按早餐 / 午餐 / 晚餐 / 加餐排列。每行右侧是"热量 · 蛋白质"小计，下面一行灰字列出食物名。同一餐的多次保存合成一行（和 B1 用同一个函数）。点一下这一行，展开每样食物的四项数值。
4. **还没记的餐**显示"+ 记{晚餐}"，点了跳到饮食页，并且已经选好这个餐次。
5. **不显示英文餐次名**：`lunch` 这类值一律用中文显示。

**验收：**
- 午餐分两次保存的那天，饮食卡只显示一行午餐，包含三样食物。
- 进度条和数字取整正确，没有长小数。

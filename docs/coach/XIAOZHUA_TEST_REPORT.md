## 0. 读这份报告前先看这三点

1. **没有任何一条用例是对真实模型执行的。** 环境里没有 OpenAI 密钥，也连不上。所以：
   - "通过"只代表**服务端逻辑**正确（用脚本化的模型输出驱动）。
   - 模型"读没读对人话"（Patch §11.2 的识别质量、30 例标注集、重量误差）**全部未执行**。明早 `npm run coach:eval`（42 条语料）是第一步。
2. **没有真机。** 浏览器检查用的是 Chromium 的手机尺寸模拟（390×844，触摸），不是 iOS Safari / Android Chrome。键盘遮挡、安全区、录音都**未执行**。
3. **验证环境不是 Supabase。** 是本地 Postgres 16 + PostgREST 12.2.3（带真实 RLS）+ 极简的登录/模型替身（`scripts/local-supabase/`）。线上库的迁移状态、线上 PostgREST 版本、Netlify 超时都**未验证**。

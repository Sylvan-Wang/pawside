# 线框与交互状态（草图）

ASCII 线框，宽度按手机约 36 字符。**不是视觉稿**：颜色、圆角、字号沿用现有 App（`bg-gray-50`、白卡片、黑色主按钮、`CatMascot` 奶牛猫）。
每个界面列出**必须覆盖的状态**，对应 Patch §3.1。

## 1. 照片识别（PRD 01）

### 1.1 输入栏变化
```
├────────────────────────────────────┤
│ 记一餐 记运动 记体重 今天情况 吃什么│
│ ┌─────────────────────┐ 📷  🎤 ┌──┐│
│ │说说吃了什么…        │        │发送││
│ └─────────────────────┘        └──┘│
└────────────────────────────────────┘
   📷 → 底部弹出：[拍照] [从相册选] [取消]
   首次点 📷：一次性说明（见 1.6）
```

### 1.2 附件预览（发送前，可删）
```
│ ┌────┐ ┌────┐ ┌────┐                │
│ │ 🖼 │ │ 🖼 │ │ +  │  最多 5 张     │
│ │ ✕  │ │ ✕  │ │    │                │
│ └────┘ └────┘ └────┘                │
│ ┌─────────────────────┐ 📷  🎤 ┌──┐ │
│ │补充一句（可选）     │        │发送│ │
```
状态：压缩中（缩略图上转圈）· 上传中（真实进度，不用假百分比）· 失败（缩略图上 ⚠ + "重试/删除"）。

### 1.3 识别进行中（真实阶段，不做假进度条）
```
│ ┌────────────────────────┐         │
│ │ 🖼 已收到照片           │         │
│ │ ● 上传完成              │         │
│ │ ◐ 正在认食物…           │         │
│ │ ○ 估算份量与营养        │         │
│ └────────────────────────┘         │
```
超时：`没认出来。可以补一句文字，或直接记「只记吃了什么」。[再试一次] [改用文字]`

### 1.4 识别结果草稿（核心卡）
```
│ ┌────────────────────────────────┐ │
│ │ 午餐（今天）  🖼×1            │ │
│ │ 米饭        约150g   174 kcal 估算│ │
│ │ 宫保鸡丁    约200g   320 kcal 估算│ │
│ │ 汤          看不出是什么  待补 │ │
│ │ ──────────────────────────────  │ │
│ │ 已知合计 494 kcal · 另有1项待补 │ │
│ │ 看得见的：米饭、鸡丁、花生      │ │
│ │ 看不见的：用了多少油（没算）    │ │
│ │ 份量是照片估的，可以说"米饭一碗"│ │
│ │ [ 确认保存 ]  [ 取消 ]          │ │
│ └────────────────────────────────┘ │
```
要点：每行显示**依据**（"约…"= 估算；"待补"= 未知）；"看不见的"明确列出不确定项；**不出现置信度百分数**（Patch：自报 confidence 不等于校准准确度）。

### 1.5 多图分组（一次追问）
```
│ ┌────────────────────────┐         │
│ │ 这 3 张是同一餐，还是   │         │
│ │ 不同餐？                │         │
│ │ [同一餐] [分开记]       │         │
│ │ 小提示：也可以直接说     │         │
│ │ "第一张早餐，后两张午餐" │         │
│ └────────────────────────┘         │
```
未回答 → 保留一张"未归属"草稿（不伪造餐数），不再追问。

### 1.6 首次使用说明（一次，简短）
```
│ 照片只用来认食物。                  │
│ · 发给 OpenAI 识别                  │
│ · 识别后保留 7 天，可随时在这里删除 │
│ · 不用于训练模型                    │
│ [知道了]            [隐私说明]      │
```
（保留期、"不用于训练"必须和真实配置一致后才能写，见 PRD 01 §9。）

### 1.7 失败/降级清单
| 情形 | 文案方向 | 动作 |
|---|---|---|
| 非食物 | "这张看起来不是食物" | 删除/换图/文字 |
| 太暗/模糊 | "太暗了，看不清" | 重拍/文字（**最多提示一次**，不无限要求重拍） |
| 混合视角 | "这几张像是同一份食物，我按一份算" | 可改 |
| 格式不支持 | "请用 JPEG/PNG/WebP" | 换图 |
| 超大 | 自动压缩；仍超限则提示 | 换图 |

## 2. 语音输入（PRD 02）

```
默认          录音中                转写中              转写完成（可改）
┌──────────┐  ┌────────────────┐   ┌──────────────┐   ┌────────────────────┐
│ 🎤       │→ │ ● 0:07 / 1:00  │ → │ 正在转成文字…│ → │ 中午吃了一碗面     │
│          │  │ [取消] [完成]  │   │   [取消]     │   │ [重录] [发送]      │
└──────────┘  └────────────────┘   └──────────────┘   └────────────────────┘
```
错误态：无麦克风权限（"需要麦克风权限。也可以直接打字" + 如何开启的一行说明）· 没声音（"没听到声音"）· 超时（到 60 秒自动停止并转写）· 上传/转写失败（保留录音在本地内存，可重试；**不丢文字**）。
**转写文字回填输入框，用户点发送才进入聊天回合。**

照片＋语音：先选图，再按住/点 🎤 说明，转写回填到该条消息的文字框，作为**同一次输入**发送。

## 3. 食谱（PRD 03）

### 3.1 推荐卡
```
│ ┌────────────────────────────────┐ │
│ │ [封面]  番茄牛腩饭              │ │
│ │         来自：XXX（B站）        │ │
│ │         约 30 分钟 · 作者标注    │ │
│ │         作者标注热量 560 kcal*  │ │
│ │ 为什么推荐：你说想吃牛肉；      │ │
│ │ 今天蛋白质还没记满              │ │
│ │ [👍] [👎] [☆收藏] [换一个]      │ │
│ │ [去看视频 ↗]                    │ │
│ │ * 作者标注，份量口径不明，仅供参考│ │
│ └────────────────────────────────┘ │
```
- 封面失败 → 占位图（奶牛猫），不影响卡片其他部分。
- 作者热量口径不清 → **整行隐藏**。
- "为什么推荐"必须是**可追溯的理由**（命中的偏好、已记录的事实），不编造。

### 3.2 点了外链回来
```
│ 看完了？                             │
│ [我按这份吃了]  [先收藏]  [没做]     │
```
"我按这份吃了" → 走**餐草稿**（份数确认），缺营养就粗记录。**点开外链本身不算做过/吃过。**

### 3.3 无候选
```
│ 符合你条件的食谱暂时没有。           │
│ 可以放宽：[时间≤45分钟] [不限厨具]   │
│ （忌口和过敏不会放宽）               │
```

## 5. 气泡与提示（PRD 05）

```
                               ┌───────────┐
                               │hi，周报好啦│✕
                               └─────╲─────┘
                                     🐱   ← 悬浮入口，右下
```
规则可视化：一天最多一个 · 可点 ✕ 关闭（跨会话记住）· 点气泡跳到内容 · 训练执行页隐藏 · "减少动态效果"时无动画。
状态：安静（只有猫）· 有气泡 · 已关闭（当天不再出现）。

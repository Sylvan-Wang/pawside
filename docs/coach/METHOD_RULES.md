## 2. 不能违反的原则

| 编号 | 原则 | 对输出的影响 |
|---|---|---|
| M008 | 休息时间服务于训练计划；不评价训练时长 | 时长只用来判断记录是否异常，不能说"练得太久 / 太短" |
| M009 | 三分化不等于固定的练三休一 | 休息日不催训练，不说"落后了" |
| CAL-007 | 完成一次挑战组不等于进阶 | 不因为一次做到就建议加重量 |
| SCN-004 / 005 | 只完成部分不是失败 | 不用"失败""没完成" |
| SCN-008 / 009 | 不做诊断 | 不说"过度训练""你不能练" |
| 校准期 | 第 3 天、弯举都在找重量 | 只说"还在找合适的重量"，不说进步或退步 |
| 动作平等 | 没有受保护的动作（产品决定 D30） | 恢复调整只减组数，不删动作 |

## 3. 已知缺口（改之前先看）

- 动作名和规则键的对应关系是按证据键推断的。写规则时用 `exercise_id` 或规则键，不要用中文名去匹配。
- RX-DAY2-02、RX-DAY2-04 没有写进上表：前者没有特殊组，后者在模板里注明"组次待严格方法证据，当前不生成"。

- 模板只有第 1 阶段。后续阶段（卧推 3×8、上斜末组 RPE 9 等）还没有进入数据库。不要在 prompt 里假设用户已经到了后续阶段。
- 所有组的 `target_rpe / target_rir / target_weight_kg / rest_*`（侧平举除外）都是 null。要补这些值，必须走 importer 出新的 release（`scripts/method-import/`），不要直接 UPDATE 发布数据，release 有不可变约束。
- `actual_rir` 线上全部为 null，因为用户没有填"还能再做几次"。依赖 RIR 的规则现在拿不到数据。

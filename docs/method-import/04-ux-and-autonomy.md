## 1. 原则

1. **默认能用，事后可改。** 导入的理想路径不需要逐项确认；需要用户看一眼的内容集中成一个清单，并提供"全部接受建议"。
2. **自主权永远不阻止训练。** 用户的任何调整、跳过、缩短，都不会让"开始训练""完成训练"失败。沿用现有产品约束：不根据自评改处方，不说"今天别练"。
3. **诚实标注来源。** 界面上的四种标签："原文写的""动作库补的""AI 建议""我改的"。AI 建议在用户确认前不生效。
4. **不说教、不评价。** 文案沿用现有风格：不加"推荐""最佳"，不显示英文内部值，不写"没完成"，不显示训练时长作为评价（M008）。
5. **每个节点只有一个教练区块**（沿用 `CoachCard` 的约定）。

## 2. 导入流程

### 2.1 入口
- 主入口：**训练 → 方法库 → 「导入新方法」**（方法库见第 5 节）。
- 次入口：首页的方法卡片在没有私有方法时多一行小字"也可以导入你自己的训练计划"。
- **注册引导保持不变**（决策 O-18）：仍保存资料并加入官方 1.2。导入是之后才发生的事，不改变首次体验，也不增加注册的摩擦。

### 2.2 屏幕与步骤（理想路径：勾选 → 开始识别 → 开始使用，3 次点击）

**屏幕 A：粘贴**

├──────────────────────────────┤
│ 粘贴一篇训练计划的文字         │
│ ┌──────────────────────────┐ │
│ │                          │ │
│ │  （文本框，最多 30000 字） │ │
│ └──────────────────────────┘ │
│                    0 / 30000 │
│                              │

│   提供的内容，并非 Pawside   │

│   健康负责，量力而行；如有    │

**屏幕 B：识别进度**

**屏幕 E：待确认清单**（仅有待确认项时）
```
│ 3 项需要确认      [ 全部接受建议 ] │
│                                    │

### 2.3 来源标签的用户文案

| 内部标签 | 用户看到 | 是否需确认 |
|---|---|---|
| `method_explicit` | 原文写的 | 否 |
| `library_default` | 动作库补的 | 否（已审核的金标） |
| `ai_inferred` | AI 建议 | **是** |
| `user_corrected` | 我改的 | 否 |

### 2.4 异常与空状态

| 情况 | 文案与行为 |
|---|---|
| 没找到训练计划 | "这段文字里没有找到训练计划，换一段试试。"（保留文本，不扣配额以外的任何东西） |
| 超长 | 文本框计数变红，按钮不可点 |
| AI 暂时不可用 | "识别暂时不可用，你的文字已保存，可以稍后继续。" 草稿保留，不阻塞其他功能 |
| 网络中断 | 回到页面自动从上一步继续 |
| 某天识别不出动作 | 该天显示"这一天没有识别到动作"，可删除该天或手动添加动作 |

### 2.5 度量
仓库里没有埋点设施。上线初期用已有的数据代替：`user_method_imports` 的状态分布（完成率、放弃率、失败率）、待确认项数量（`open_questions_count`），以及 `ai_generations` 里 `method_import` 的失败原因。是否引入埋点另议。

## 3. 使用中的自主权

### 3.1 现有机制（保持不变）
- 开始训练前选择时长：30 / 45 / 60 / 90 分钟，默认来自注册时的偏好。
- 必须完成的动作数 = `ceil(动作数 × 分钟 / 60)`，不超过动作总数。例如 5 个动作：30 分钟 → 3 个，45 → 4 个，60 → 5 个。
- 训练中可以把时长往小改，不能往大改。
- **这就是"五个动作里只做三个"的现有实现**：达到阈值即可完成训练，其余动作仍可继续做。

### 3.2 新增：调整（个人调整层，文档 2 第 7 节）
入口在训练页每个动作卡的「⋯」菜单：

```
┌──────────────────────┐
│ 换一个动作           │  → 从金标替换列表里选 2–3 个
│ 这个动作我不做       │
│ 调整组数 / 次数      │  → 加减按钮
│ 太难了               │  → 见下
└──────────────────────┘
```
日卡上另有一项"跳过这一天"。

**作用范围**：点任一项后弹出一个选择：
```
│ 应用到哪里？                    │
│ [ 以后都这样 ]  [ 只这一次 ]    │
```
- 以后都这样：写入调整层，之后生成的处方都生效。
- 只这一次：只改今天还没开始的处方。
- 可在「训练 → 方法 → 我的调整」里逐条撤销。

**"太难了"**：一个底部弹层，两个选项：
- 换更容易的动作（来自金标的 `regression`，没有就不出现这一项）
- 少做一组

**约束**
- 任何调整都不阻止开始或完成训练。
- 调整后的动作数就是完成阈值的基数（调整在生成处方时生效，开始训练时统计的就是调整后的数量）。
- "换一个"只能换成该动作的金标替换列表里的动作，不开放任意搜索。
- 已开始的训练里，调整只影响尚未做的动作；已记录的组不动。

## 4. 健康与安全提示

- 声明只在导入时出现一次，不在每次训练时重复。
- 金标里带风险标记的动作（如硬拉、力竭），在摘要卡展开日详情时显示一行小字"新手请从轻重量开始，动作不确定先找教练确认"。**只提示，不拦截。**
- 训练中出现疼痛的提示沿用原文里的安全说明，由用户导入的内容决定；系统不额外生成医学建议。

**状态 B：周一，上周刚结束**：上周复盘置顶并带"新"，今日复盘折叠在下方。
**状态 C：1 号，上月和上周同时结束**：月复盘置顶，上周复盘折叠并带"新"，日复盘再往下。

**规则**
- 层级优先级：月 > 周 > 日。
- 置顶的是"已结束、且未读或在保留期内"的最高层级；否则置顶日复盘。
- 周以周一为起点（沿用 `getWeekStartKey`）；按用户时区计算。
- 进行中的周期只显示事实（记录了几天、训练几次），不生成 AI 文字。
- 数据不足时如实显示："本周只记录了 N 天，暂不生成复盘。"
- 每张卡都使用 `CoachCard`（四态），"基础总结"必须带标签，不得冒充 AI。
- 趋势方向由规则引擎判定，AI 只做解释，沿用周复盘现有约束。
- **不显示训练时长**（M008），月复盘同样。

```

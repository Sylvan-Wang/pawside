# 周六复盘

## 周报（周五 20:30 的例程生成，周六上午复盘，标签 `weekly-retro`）

1. 本周数字：待决策共几条，被采纳 / 跳过 / 改写各几条；PR 开了几个、合并几个、打回几个；新进 backlog 几条、关掉几条；人工破格 P0 几条。
2. 线索：本周最有价值的 3 条，各自后来怎样了；哪些赛道一直没数据。
3. 指标：注册数、DAU、付费意向（拿不到数据就写「拿不到」和原因）。
4. 系统自评：哪些天的待决策大多被跳过；哪类工作反复被打回。
5. 建议的调整（最多 3 条）：改关键词、改分诊规则、改例程。每条都写成可选项。

## 之后

下一轮例程把打分和意见追加到 `RETRO_LOG.md`，并对采纳的调整开 PR（改文档或 `sources.yml`）。合并后生效。没有回复的周报不做任何调整。

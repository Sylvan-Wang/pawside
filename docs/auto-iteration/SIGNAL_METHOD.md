# 信号分析方法

改编自 ai_companion_signal_agent 的 product insight skill，用于 Pawside。每日例程读 `signals-data` 分支的 `signals/YYYY-MM-DD.md`（和同名 `.json`）后按这里的步骤分析。

## 0. 先看来源健康

- 正常来源少于一半：在当日 issue 写「采集异常」，列出失败的来源；当天线索部分改用网页搜索补（只读公开页面），并注明来源。
- 连续 3 天 Reddit 全部失败：放进待决策，选项包括换数据源（如 PullPush、Product Hunt、YouTube 评论）。
- 某个赛道连续 7 天 0 条：在周报里建议改关键词或版块。

## 1. 开放编码

逐条读，用这些维度记下原话（不要改写）：

- 用户需要：想要什么结果
- 痛点：现有产品或做法哪里让人烦
- 坚持障碍：为什么练不下去 / 记不下去
- 对 AI 教练的期待和不信任
- 价格和付费：订阅、免费替代、愿意为什么付钱
- 竞品提及：Fitbod、Hevy、MyFitnessPal、MacroFactor、Strong、Keep、ChatGPT 等
- 变通做法：用户自己拼凑的方法（Excel、备忘录、ChatGPT 对话）
- 出海相关：英文用户的习惯、单位、文化差异
- 风险：伤病、进食障碍倾向、极端节食、隐私

## 2. 归类成主题，保留矛盾

同一主题下的相反说法分开记。

## 3. 形成洞察

每条洞察至少 2 条不同证据；不够就标「待跟进」。类型：用户需要、坚持障碍、产品机会、定位信号、付费信号、留存机会、体验问题、出海信号、风险信号、竞品动态。

## 4. 打分

各维度 1–5：频次、情绪强度、战略相关（对照 TRIAGE_RULES 第 5 节当前重点）、可执行（1–2 周内能试）、新颖、风险等级。

- 机会分 = 频次 + 情绪强度 + 战略相关 + 可执行 + 新颖；≥20 高，13–19 中
- 风险分 = 频次 + 情绪强度 + 战略相关 + 风险等级；≥16 高，10–15 中
- 情绪强度 5 但频次 1：只算待跟进
- 机会和风险分开列，不混在一起排

## 5. 对应到行动

| 信号 | 建议的行动 |
|---|---|
| 反复出现、能做成功能 | 进 backlog，附研发草案 |
| 说法有分歧 | 定位或文案测试 |
| 价格和付费 | 付费意向实验（如官网预约、额度） |
| 新手不懂 | 新手导览或内容 |
| 适合出海的话题 | 英文内容草稿 |
| 伤病、进食障碍 | 只记风险，不做增长动作 |

## 6. 伦理边界

- 不诊断，不推断个人健康状况。
- 不把脆弱用户的内容当成拉新机会。
- 不保存用户名和个人主页；引用时匿名。
- 只读公开内容；不自动发帖、评论、私信。
- Reddit 信号是方向性的定性信号，不是市场证明；重大决定之前要用访谈或数据验证。

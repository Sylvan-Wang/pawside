**标题（20 字内，三选一）**
- 不称重，也能知道今天蛋白够不够

- 记饮食别逼自己算到克

**正文**

我记饮食坚持不下来，原因很简单：
每顿都要掏秤、查表、算到克，三天就烦了 🫠

后来换了个想法：**记个大概，比完全不记强。**

我现在是这样记的👇

🍱 吃完外卖，写下吃了什么，克数估个大概就行（一份饭大概 200–300g，一块鸡腿大概 100g）
🔁 常吃的东西点一下就能填上次的分量，不用每次重输
📊 一天下来看一眼：热量和蛋白质还差多少

还有一个对我很有用的点：
早餐、午餐、晚餐各给一个大概的热量区间，**只是参考，不是必须吃满的处方**。
哪顿多吃了一点，晚饭少一点就行，不用有负罪感。

懒得一项项填的时候，也可以直接打一句话，比如「中午吃了鸡腿饭加一杯无糖豆浆」，先出一张卡片给我看，我点确认了才算记上。

我在做的小工具 Pawside 就是按这个思路做的（说明一下我是做它的人）。
数字都是估算，品牌不同会有差别，所以它会标出哪些是估算、哪些是你自己填的。

👉 目标不是每一克都准，而是知道「今天蛋白大概够没够」。

你们记饮食最烦的是哪一步？称重、查热量，还是根本想不起来记？评论区说说 📝

## 3. 每句对过什么

| 文中说法 | 依据 |
|---|---|
| 写下吃了什么，克数估个大概 | `app/food/FoodPageClient.tsx`：每条食物要填名称和重量（g），输入框提示「例如 150」；没有称重设备的要求 |
| 常吃的东西点一下填上次的分量 | 同文件「最近常吃 · 点击快速填入」，选中后「已按历史记录填入相同分量与营养」；`/api/food/history?limit=8` |
| 一天下来看热量和蛋白质还差多少 | 同文件「今日营养进度」：热量 / 蛋白质 / 碳水 / 脂肪，每行「还可参考摄入 N」或「已超过参考 N」 |
| 早午晚各一个热量区间，只是参考 | `lib/nutrition/guidance.ts` `buildMealCalorieRanges`（注释：Non-binding meal guidance）；页面原文「餐次热量仅作参考」「不是必须吃满的固定处方」 |
| 打一句话，先出卡片，确认了才记上 | `lib/site/features.ts` `xiaozhua-chat`（live）：「用一句话记饮食、运动和体重，先出卡片，你确认了才保存」；写入只经 `lib/coach-chat/commit.ts` |
| 标出哪些是估算、哪些是你填的 | 页面来源标签：食物数据库 / AI 估算 / 你填写的 / 上次确认（`food.source.*`） |
| 品牌不同会有差别 | 页面原文「不同品牌可能有明显差异。」 |

没写的：拍照识别（`planned`）、英文界面（开关默认关）、食谱推荐（未发布）、价格。

**标题（20 字内，三选一）**
- 站在器械前发呆？新手这样排就不乱
- 健身房新手：下一个动作练啥不用想
- 别再看到空器械就上了

**正文**

刚开始去健身房，我最尴尬的时刻不是不会做，而是**站在器械区不知道下一个该练什么** 🧍

想练的器械有人在用，就随便找个空的做两组；做完也不知道够不够，回家感觉啥都没练到。

后来我发现，乱的不是动作，是**每一步都在临场决定**。

现在我是这么练的👇

📋 进门之前，今天练什么、哪几个动作、按什么顺序，已经排好了
🔢 每一组写着是热身组还是正式组，目标做几次，要不要做到力竭（力竭 = 做到真的一个都推不动了）
🎞 每个动作旁边有示意图，忘了怎么做瞄一眼就行
⏭ 器械被占了？这个动作点「稍后做」，先练下一个，回头再补

还有一点对新手很友好：
**热身组不用做重**，正式组才是要认真的那几组。以前我每组都拼尽全力，练到第三个动作就没劲了 😮‍💨

做完一组，填一下重量和次数，点一下就记上了。不用另开备忘录。

我在做的小工具 Pawside 就是按这个思路做的（说明一下我是做它的人）。
训练方法是按公开的训练思路整理的，只是参考，身体不舒服就停下。

👉 目标不是每次都练到最累，而是每次进门都知道下一步做什么。

你们在健身房最容易卡在哪一步？找器械、不会做，还是不知道做几组？评论区说说 💬

## 3. 每句对过什么

| 文中说法 | 依据 |
|---|---|
| 今天练什么、哪几个动作、按什么顺序已经排好 | `lib/site/features.ts` `today-plan`（live）：「打开就是今天的部位、动作和每组目标」；`app/training/today/page.tsx` |
| 每组写着热身组还是正式组、目标几次、要不要做到力竭 | `lib/coach/set-guidance.ts` `SET_TYPE_LABELS`（热身组 / 正式组 / 力竭组 / 休息-暂停组 / 递减组）和 effort 文案（「不做到力竭」「做到接近力竭」）；训练页 `app/training/sessions/[sessionId]/page.tsx` 每组标题「第 {n} 组 · {label}」、下一行「目标 {target}」。计划里没有预设组次的动作不会显示，文中说「每一组写着」只适用于有预设的动作，配图要选有预设的动作截 |
| 每个动作旁边有示意图 | `components/workout/ExerciseMotion.tsx`，训练页 `exercise.media` 存在时显示；`features.ts` `exercise-motion`（live） |
| 点「稍后做」先练下一个，回头再补 | 训练页「稍后做」按钮（`session.exercise.later`）跳到下一个动作，没记录的动作不会被标完成；回头从顶部动作选择条（`session.header.viewAria`「查看动作 {n}」）点回去再练。最后一个动作上「稍后做」不可点 |
| 热身组不用做重 | 白话解释热身组含义，不给具体重量；和笔记 1「热身 15 次」一致 |
| 填重量和次数，点一下就记上 | `session.set.finish`「完成这一组」；`features.ts` `set-logging`（live） |
| 训练方法按公开训练思路整理，仅供参考 | 同笔记 1 免责声明 |

# Pawside Internal Beta 用户测试日志

> 记录日期：2026-09-25  
> 证据类型：用户现场反馈，尚未完成数据库事件复核

## 原始反馈

- 部分训练日预计时长接近两小时，开始前产生畏难情绪。
- 一次处方包含五个动作，用户完成四个后体力不支，无法继续第五个动作。
- 训练现场需要手动换算 lb 与 kg，录入负担明显。
- 用户报告仅进入三分化训练页面后，下次进入却显示已推进，且无法回退。

## 事实边界

- “4/5 动作后体力不支”和“lb/kg 换算不便”为已记录的用户体验事实。
- “仅查看导致推进”为用户观察；当前源码审计未发现 GET/页面预取直接写入或推进状态，需结合受影响账号的会话、处方、Cycle 与完成事件进一步复核。
- 在完成数据复核前，不把该现象归因于具体用户操作，也不直接批量回退历史 Cycle。

## 对应优先级

1. P0：修复 Session 完成判定、恢复与幂等推进，提供历史状态诊断和受控修复方案。
2. P1：在开始训练前按时间与当日体力生成可追溯的执行版本，不覆盖原始处方。
3. P2：训练记录支持 kg/lb 就地切换，数据库继续以 kg 作为规范单位。

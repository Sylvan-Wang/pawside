

# 爪边

一个帮你「按自己计划生活」的健身记录工具。

不替你做决定，不推销完美方案。
只帮你看清自己在做什么，给出最小、最可执行的下一步建议。

## 为什么做这个

大多数健身 App 要么功能过重，要么一直在「优化」你的生活方式。
爪边的设计思路不同：你定目标，你决定节奏，App 只负责帮你记录、看见、微调。

## 核心功能

- **快速记录**：训练、饮食、体重，30 秒完成一条
- **每日复盘**：AI 基于你当天的数据，给出 1-3 条最小行动建议
- **每周报告**：训练完成度、热量趋势、体重变化一目了然
- **身心平衡导向**：建议基于你自己的目标（减脂 / 增肌 / 保持），不强加标准

## 技术栈

- Next.js (App Router + TypeScript)
- Supabase (Postgres + Auth)
- Tailwind CSS
- Netlify 部署

## 设计原则

- 记录摩擦越低越好
- AI 只负责解释和建议，不替代你的判断
- 营养数据由结构化食物库计算，不靠 LLM 瞎估
- AI 输出与原始数据分开存储，支持 prompt 版本追踪
